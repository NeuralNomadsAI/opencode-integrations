# Licences of the parts of this package

| Part                                              | Path                                       | Licence                                                                                                                                                            |
| ------------------------------------------------- | ------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| The plugin and its method manifests               | `dist/`, `methods/`                        | MIT (`LICENSE`)                                                                                                                                                    |
| The fixed programs the plugin runs inside Blender | `programs/`                                | GPL-3.0-or-later (SPDX header of each file; the GNU GPL version 3 text is the `LICENSE` inside the add-on archive)                                                 |
| The OpenCode Link add-on, embedded as an archive  | `host/blender/opencode_link-<version>.zip` | GPL-3.0-or-later (`LICENSE` inside the archive); some handlers carry GPL-2.0-or-later headers, compatible with it                                                  |
| Blender Lab's tool code, inside the add-on        | `lab/` in the add-on archive               | GPL-3.0-or-later, Blender Authors: copied from Blender Lab `blender_mcp` v1.0.3 (commit `2cea8d566dde07fbac28a61d698909d69724e853`), each file with its SPDX lines |

The `license` field of `package.json` is `MIT AND GPL-3.0-or-later`, as the repository's packaging rules require of a package that embeds a GPL-3.0-or-later application part: the plugin's licence and the add-on's. The programs run in Blender's Python like the add-on and share its licence. No Blender documentation is bundled: `blender_inspect` reads the running Blender and links the official documentation of its version.
